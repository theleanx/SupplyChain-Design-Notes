# Module 2 Fictional Datasets

These CSV files support **Module 2 — Network Design, Digital Connectivity, and Performance**. All organizations, network options, technology economics, exceptions, master-data records, transportation lanes, service measures, financial values, and operating metrics are fictional and independently created for learning.

## Dataset map

| Dataset | Primary learning use |
|---|---|
| [`network-alternatives.csv`](section-a/network-alternatives.csv) | network configuration, service, cost, and resilience comparison |
| [`technology-business-case.csv`](section-a/technology-business-case.csv) | technology investment, payback, ROI, and risk |
| [`network-exceptions.csv`](section-b/network-exceptions.csv) | event management and control-tower decisions |
| [`master-data-quality.csv`](section-b/master-data-quality.csv) | data quality, cleansing, and stewardship |
| [`transport-lanes.csv`](section-b/transport-lanes.csv) | transportation execution and visibility |
| [`customer-service-metrics.csv`](section-c/customer-service-metrics.csv) | perfect-order and customer-service analysis |
| [`working-capital.csv`](section-c/working-capital.csv) | cash-to-cash and working-capital calculations |
| [`supplier-health.csv`](section-c/supplier-health.csv) | supplier financial-health evidence |
| [`operations-scorecard.csv`](section-c/operations-scorecard.csv) | operational quality, capacity, and maintenance metrics |

# Module 4 Fictional Datasets

All files in this directory use independently created, fictional data for **Pinehaven Motion Systems**. They are designed to support the Module 4 learning pages, worked calculations, visuals, and integrated capstone.

The values are illustrative rather than operational recommendations. Units, horizons, and assumptions are carried in the files so calculations can be reproduced.

## Files

- `master-schedule.csv` - MPS, PAB, ATP, and time-fence examples
- `bom-structure.csv` - fictional multilevel bill of material
- `mrp-planning.csv` - gross-to-net MRP, lot sizing, receipts, releases, and exceptions
- `drp-network.csv` - time-phased distribution replenishment
- `capacity-plan.csv` - long-/medium-range capacity scenarios
- `capacity-work-centers.csv` - utilization, efficiency, rated/demonstrated capacity, load, and PAC
- `inventory-item-master.csv` - inventory classification and ABC data
- `inventory-financials.csv` - inventory/financial-statement bridge
- `replenishment-models.csv` - EOQ, order-point, periodic-review, min-max, TPOP, and buffer examples
- `traceability-cycle-count.csv` - genealogy and inventory-count records
- `returns-disposition.csv` - disposition decision examples
- `operations-kpis.csv` - operational performance and improvement metrics
- `quality-tools-data.csv` - shared data for Pareto, control, scatter, and network-tool examples
- `lean-flow.csv` - value-stream, waste, JIT, kanban, and takt analysis
- `improvement-projects.csv` - DMAIC and constraint-management examples

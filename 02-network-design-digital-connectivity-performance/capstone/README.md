# AsterWorks Network Transformation Capstone

This capstone integrates Module 2 into one executive decision. AsterWorks Equipment must support European growth without allowing service, working capital, or operating risk to deteriorate.

## Situation

AsterWorks currently serves all customers from one assembly plant and one North American distribution center. European orders are growing, but average transit time is high and expedited freight is increasing. The company is considering a European postponement center, upgraded planning and execution applications, partner event integration, and a new performance system.

## Your assignment

Prepare a recommendation covering five decisions:

1. **Network:** Which configuration best fits the service and financial objectives?
2. **Technology:** Which capabilities are required now, and which can wait?
3. **Data:** Which master-data objects and controls are critical to launch?
4. **Risk:** What legal, privacy, cybersecurity, and partner risks need controls?
5. **Performance:** Which measures should executives review monthly?

Use the Module 2 datasets and state all assumptions. Your recommendation should identify trade-offs, not simply select the alternative with the lowest visible cost.

## Required outputs

- one-page executive recommendation;
- weighted network-alternative comparison;
- technology business case with ROI and payback;
- target application and information-flow sketch;
- critical-data control table;
- metric tree with targets, owners, and review cadence; and
- 90-day, one-year, and two-year roadmap.

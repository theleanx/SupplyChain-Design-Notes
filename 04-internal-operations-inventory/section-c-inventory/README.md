# Section C — Inventory

Section C turns inventory from a warehouse count into a controlled supply-chain decision. The learning path moves from **what inventory is and why it exists**, through **where it should be positioned and how it should be governed**, into **financial and replenishment decisions**, and finally into **traceability, accuracy, end-of-life, and disposition**.

All examples, numbers, questions, and diagrams in this section are independently created for this repository. Pinehaven Motion Systems is fictional. Official APICS/ASCM text, artwork, presentation slides, flashcards, and question-bank questions are not reproduced.

## What you should be able to do after Section C

You should be able to explain the main physical types and business functions of inventory; select a control intensity based on value and criticality; connect inventory to working capital and financial statements; calculate EOQ, reorder point, periodic-review targets, average inventory, and turnover; choose among replenishment logics; distinguish safety quantity from safety time; design traceability and count controls; and make gated end-of-life/disposition decisions.

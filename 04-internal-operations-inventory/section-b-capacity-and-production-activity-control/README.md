# Section B: Capacity and Production Activity Control

Capacity planning translates supply commitments into realistic resource capability and then controls production as the plan reaches daily execution.

This section follows fictional **Pinehaven Motion Systems**, a manufacturer of industrial servo drives. All examples, values, diagrams, datasets, and assessment questions are independently created for this repository.

## Learning outcomes

After completing Section B, you should be able to:

- place resource planning, RCCP, CRP, and capacity control on the correct planning horizons;
- build and interpret resource profiles and capacity-growth scenarios;
- validate an MPS against critical resources and a detailed MRP load against work-center capacity;
- calculate utilization, efficiency, rated capacity, and demonstrated capacity correctly;
- choose between capacity-side and load-side responses when work is out of balance; and
- improve production flow using constraint logic, kanban, demand pull, and disciplined execution feedback.

## How to study the section

Trace one capacity question through the planning hierarchy: **Can the long-range production plan be supported? Can the MPS pass its bottleneck check? Can detailed work-center load be executed? Is actual production staying within control?** Then connect the answer to the correct response instead of assuming every gap requires more equipment.

Every lesson contains an original decision visual, a fictional operating example, an applied artifact or calculation, trade-offs, common mistakes, and an original knowledge check.

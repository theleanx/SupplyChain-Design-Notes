# Module 3 Datasets

All values are fictional and independently selected for learning purposes.

| Dataset | Decision use |
|---|---|
| [make-buy-options.csv](section-a/make-buy-options.csv) | Capability and sourcing-model comparison |
| [total-cost-options.csv](section-a/total-cost-options.csv) | Quote-to-total-cost bridge |
| [category-spend.csv](section-b/category-spend.csv) | Spend, supplier count, and concentration |
| [category-portfolio.csv](section-b/category-portfolio.csv) | Impact and supply-risk classification |
| [supplier-shares.csv](section-b/supplier-shares.csv) | Parent-level source shares and HHI calculation |
| [design-alternatives.csv](section-c/design-alternatives.csv) | Design complexity and lifecycle comparison |
| [supplier-evaluation.csv](section-d/supplier-evaluation.csv) | Raw 1–5 supplier scores, explicit weights, gates, and totals |
| [open-order-exceptions.csv](section-d/open-order-exceptions.csv) | Exception prioritization and recovery |
| [contract-obligations.csv](section-d/contract-obligations.csv) | Contract deployment and evidence ownership |
| [three-way-match.csv](section-d/three-way-match.csv) | Quantity and price match exceptions |

The make-or-buy file states its evaluation horizon and discount-rate assumption. The design-alternatives file includes one-time conversion cost and validation risk so the best recurring-performance option is not automatically the best release decision.

# Integrated Capstone

## Decision Context

Describe one fictional organization, the operating problem, decision horizon, customer
consequence, and financial or risk boundary.

## End-to-End Decision Flow

Include a Mermaid flow that connects the module's sections into one decision system.

## Source Data

Link every required CSV directly. State units, time horizon, conventions, and any base
assumptions that apply across tasks.

## Assignment

Require the learner to:

1. validate the problem and assumptions;
2. reproduce the quantitative baseline;
3. compare feasible alternatives and trade-offs;
4. apply mandatory gates before ranking;
5. create practitioner-ready decision artifacts; and
6. define owners, controls, triggers, and an implementation sequence.

## Required Outputs

List named tables, calculations, diagrams, registers, and the executive recommendation.

## Decision Checks

Include scenario questions with complete answer rationales.

Complete the capstone before opening the module's `solution-guide.md`.

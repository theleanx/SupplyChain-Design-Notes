# Section A: Introduction to Supply Chains

> **Status:** Complete. This section combines original explanations, examples, questions, and diagrams into a practitioner-oriented introduction to supply chains.

## Learning objectives

By the end of this section, you should be able to:

- explain a supply chain as a network of entities, processes, and flows;
- distinguish product/material, information, funds, strategic-requirement, and reverse flows;
- explain why value creation and balance across participants matter;
- compare vertical integration with lateral (horizontal) integration;
- describe a five-stage supply-chain maturity model; and
- recognize how manufacturing, service, and specialized supply chains can differ while still using the same core supply-chain logic.

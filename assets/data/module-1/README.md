# Module 1 Fictional Datasets

These datasets support **Module 1 — Supply Chains, Demand Management, and Forecasting**. All organizations, demand histories, service patterns, forecasts, errors, and planning values are fictional and independently created for learning purposes.

## Dataset map

| Dataset | Primary learning use |
|---|---|
| [`northstar-demand-history.csv`](capstone/northstar-demand-history.csv) | integrated NorthStar capstone demand history |
| [`northstar-seasonal-demand.csv`](section-d/northstar-seasonal-demand.csv) | seasonality, deseasonalizing, and reseasonalizing |
| [`forecast-method-comparison.csv`](section-d/forecast-method-comparison.csv) | moving-average and smoothing method comparison |
| [`service-hourly-demand.csv`](section-d/service-hourly-demand.csv) | service-sector forecasting |
| [`associative-regression-example.csv`](section-d/associative-regression-example.csv) | associative forecasting and regression practice |
| [`forecast-error-example.csv`](section-d/forecast-error-example.csv) | forecast error, bias, MAD, tracking signal, MSE, and MAPE |
| [`demand-review-example.csv`](section-e/demand-review-example.csv) | demand-review and S&OP evidence |

## Use rules

1. Treat every value as fictional training data.
2. Keep the stated time period, units, and sign conventions visible when calculating.
3. Use the [forecasting formula sheet](../../../calculations/forecasting/formula-sheet.md) for controlled definitions used by the repository.
4. Do not interpret a single error metric or correlation measure as a decision without the business context and planning consequence.

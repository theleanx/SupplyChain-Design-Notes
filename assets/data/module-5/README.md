# Module 5 Fictional Datasets

These datasets support **Module 5 — Forward and Reverse Logistics**. All organizations, products, lanes, sites, costs, capacities, trade scenarios, returns, and waste streams are fictional and independently created for learning purposes.

The data are intentionally reusable across lessons and the integrated HarborPeak capstone. Regulatory fields are training controls rather than live legal determinations. A real transaction requires current jurisdiction-specific customs, transportation, safety, environmental, tax, and hazardous-material verification.

## Final dataset map

| Dataset | Primary learning use |
|---|---|
| `logistics-strategy.csv` | total-logistics-cost and 3PL/4PL decisions |
| `warehouse-network.csv` | warehouse count, ownership, service, and total-cost trade-offs |
| `warehouse-capacity.csv` | multi-year warehouse-space sizing |
| `material-handling.csv` | handling capability, safety, automation, labor, and cost decisions |
| `transportation-capacity.csv` | forward-looking lane and mode capacity |
| `warehouse-operations.csv` | receive, put-away, pick, pack, cross-dock, postponement, and kitting execution |
| `fulfillment-strategies.csv` | channel and fulfillment architecture |
| `distribution-networks.csv` | inventory ownership and customer-delivery paths |
| `transport-mode-selection.csv` | shipment density, service gates, and mode comparison |
| `carrier-options.csv` | carrier-class and provider selection |
| `trade-compliance-register.csv` | shipment-level compliance evidence and release gates |
| `incoterms-decision-cases.csv` | Incoterms® 2020 selection practice with named-place discipline |
| `border-cost-classification-cases.csv` | synthetic classification and illustrative import-cost arithmetic |
| `reverse-flow-cases.csv` | return reasons, warranty status, triage, and disposition routing |
| `reverse-cost-cases.csv` | reverse-logistics cost/revenue economics |
| `waste-disposition-cases.csv` | waste hierarchy, recovery routes, custody, and compliance gates |

## Use rules

1. Treat all values as fictional training data.
2. Apply mandatory service, safety, capability, legal, product-integrity, and chain-of-custody gates **before** economic ranking.
3. Do not replace shared values with one-off lesson numbers unless the lesson clearly labels a sensitivity case.
4. Use the [Module 5 formula and control sheet](../../../calculations/logistics-trade-reverse/formula-sheet.md) for controlled calculation definitions.
5. Reverify any time-sensitive regulatory statement against an authoritative current source before operational use.

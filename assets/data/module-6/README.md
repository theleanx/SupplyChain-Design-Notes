# Module 6 Fictional Datasets

These datasets support **Module 6 — Supply Chain Relationships**. All companies, accounts, suppliers, events, scores, costs, service results, certifications, and communication records are fictional and independently created for learning.

## Dataset map

| Dataset | Primary learning use |
|---|---|
| [`customer-segments.csv`](customer-segments.csv) | customer value, profitability, and relationship-tier evidence |
| [`customer-channel-preferences.csv`](customer-channel-preferences.csv) | customer contact-channel preference and service-treatment design |
| [`customer-lifecycle-accounts.csv`](customer-lifecycle-accounts.csv) | retention, churn, vulnerable accounts, win-back/new-account context |
| [`customer-voc-interactions.csv`](customer-voc-interactions.csv) | VOC, complaints, response attainment, service recovery, corrective-action closure |
| [`crm-technology-cases.csv`](crm-technology-cases.csv) | CRM process/data/security gates and three-year training economics |
| [`customer-service-performance.csv`](customer-service-performance.csv) | fill rate, on-time delivery, OTIF, stockouts, complaints, and response performance |
| [`supplier-segmentation.csv`](supplier-segmentation.csv) | evidence for ongoing SRM governance intensity |
| [`supplier-sourcing-relationships.csv`](supplier-sourcing-relationships.csv) | sole/single/multisource concentration and relationship risk |
| [`strategic-alliance-cases.csv`](strategic-alliance-cases.csv) | alliance hard gates followed by weighted training ranking |
| [`supplier-performance.csv`](supplier-performance.csv) | delivery, quality, corrective-action, internal-customer, technology, cost, and responsiveness evidence |
| [`supplier-certification.csv`](supplier-certification.csv) | certification gate/status training logic and requalification cadence |
| [`relationship-communications.csv`](relationship-communications.csv) | communication-plan ownership, evidence, feedback, and action closure |

## Use rules

1. Treat every row as fictional training data.
2. Preserve the stated denominator, time horizon, units, and eligibility rules when reproducing a metric.
3. Use the [relationship-performance formula/control sheet](../../../calculations/relationship-performance/formula-sheet.md) for Module 6 controlled definitions.
4. Calculations explicitly labeled **repository-defined training controls** are not represented as ASCM formulas.
5. Module 6 consumes, rather than reteaches, broader metric architecture, technology business-case, sourcing-selection, quality-improvement, and logistics-execution methods from Modules 1–5.
